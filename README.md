# 한강 낚시

[공개 앱 열기](https://workflow0521.github.io/hanriver_fishing/) · 로그인 없이 열 수 있습니다.

뚝섬·양화/선유도·망원·반포의 관측 수위, 기상청 날씨, 인천 조석을 지도와 요약 카드로 보여주는 설치형 웹 앱입니다. 물돌이 카드에서 최근 6시간 수위표를 열 수 있습니다. 휴대폰 브라우저의 **홈 화면에 추가**로 설치할 수 있습니다.

- 수위는 15분 이상 지난 실제 관측을 표시합니다. 수위표에서 누락 시각은 미수신으로 표시합니다.
- 공개 자료는 약 15분 간격으로 갱신을 시도합니다. 기관 응답과 GitHub 작업 대기에 따라 지연될 수 있습니다.
- 수위는 관측소 높이로 현장 수심과 다릅니다. 조석 보정은 임시 참고값이며 실제 유속 반전이나 입질 시각을 보장하지 않습니다.
- 방문자가 조회하는 자료에는 API 키가 포함되지 않습니다. AI 조언은 관리자가 따로 생성해 게시한 경우에만 조회됩니다.

## 코드

`dashboard/`는 앱 화면과 설치 리소스입니다. `scripts/build-pages.mjs`가 이를 GitHub Pages 경로에 맞게 변환합니다. `src/`는 관측·예보 처리와 수위 종합 분석, `scripts/collect.mjs`는 서버에서 공개용 자료를 수집하는 코드입니다.

```sh
node scripts/build-pages.mjs
node --test scripts/test-pages.mjs
node scripts/collect.mjs
```

공개 설정과 재배포는 [배포 안내](DEPLOYMENT.md)를 참고하세요.
