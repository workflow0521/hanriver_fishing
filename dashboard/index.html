수위 15분 지연 기준 · 10분마다 새로 확인

지도에서 구역을 선택하세요. 수위는 10분 관측, 날씨는 시간별 자료이며 관측 시각을 함께 표시합니다.

지도 안내 · 낚시금지구역 확인낚시구역은 공식 안내에서 확인하세요.

위 그림은 구역 선택용 개략도이며 실제 좌표·금지구역 경계·현재 위치를 나타내지 않습니다. 서울시 안내에는 선유도공원 전체와 뚝섬·망원·반포의 일부 구간 등이 금지구역으로 기재되어 있습니다. 공원 이름만으로 낚시 가능 여부를 판단할 수 없습니다.

강수자료 확인 중

관측 자료를 확인 중입니다.

강수는 앞으로 5개 시간별 예보의 최대 확률입니다. 5시간 전체의 비 올 확률을 합산한 값은 아닙니다. 바람은 앱의 낚시용 구분으로 없음 <0.3 / 조금 <1.6 / 약간 <3.4 / 중간 <8 / 강풍 ≥8 m/s이며 공식 강풍특보 등급과 다릅니다. 수위 전환 후보는 최신 관측 직전 1시간의 곡선을 연장한 실험 추정입니다. 7개 관측과 감속 일관성이 있을 때만 1시간 이내 후보를 계산합니다. 표시 여유 ±20분은 통계적 신뢰구간이 아닙니다. 실제 유속 반전인 물돌이 예보가 아니며, 낮은 정확도로 낚시 시점을 확정하는 데 쓸 수 없습니다.

강수는 앞으로 5개 시간별 예보의 최대 확률입니다. 5시간 전체의 비 올 확률을 합산한 값은 아닙니다. 바람은 앱의 낚시용 구분으로 없음 <0.3 / 조금 <1.6 / 약간 <3.4 / 중간 <8 / 강풍 ≥8 m/s이며 공식 강풍특보 등급과 다릅니다. 수위 전환 후보는 최신 관측 직전 1시간의 곡선을 연장한 실험 추정입니다. 7개 관측과 감속 일관성이 있을 때만 1시간 이내 후보를 계산합니다. 표시 여유 ±20분은 통계적 신뢰구간이 아닙니다. 실제 유속 반전인 물돌이 예보가 아니며, 낮은 정확도로 낚시 시점을 확정하는 데 쓸 수 없습니다.
